# 赤城经济 (Chicheng Jingji)
一款为 Minecraft 添加售货机、收银机和完整经济系统的模组

https://img.shields.io/badge/NeoForge-21.1.232-blue
https://img.shields.io/badge/Minecraft-1.21.1-green

📖 简介
赤城经济模组为 Minecraft 服务器或单人游戏提供了完整的虚拟货币系统（赤城币），并加入了功能完善的售货机和收银机方块。
玩家可以放置售货机并上架任意物品（支持附魔、NBT 等），其他玩家支付赤城币即可购买；收益会自动分配给售货机所有者（在线实时到账，离线暂存并于上线时补发）。
收银机则允许玩家直接向指定所有者转账，方便团队或服务器内交易。
同时模组内置了余额 HUD、经济命令等辅助功能。

## ✨ 主要功能
🛒 售货机
放置即绑定：方块放置者自动成为所有者。

上架商品：所有者手持物品右键售货机，设置单价和库存（支持任意物品，保留附魔等 NBT）。

购买商品：任何玩家右键售货机打开购买界面，选择商品并输入数量，系统自动检查余额和背包空间。

收益分配：

所有者在线 → 收益实时到账。

所有者离线 → 收益暂存于售货机，玩家上线后自动补发并提示。

数据持久化：商品列表、所有者、收益等保存至存档，重启不丢失。

保护机制：只有所有者可以破坏售货机；破坏时内部所有商品会掉落。

实时同步：多人模式下所有界面自动刷新。

🧾 收银机
放置绑定：放置者自动成为所有者。

转账功能：其他玩家右键打开转账界面，输入金额即可向所有者转账（即时到账，无需手动领取）。

所有者提示：所有者右键显示提示信息，不会打开转账界面。

保护机制：只有所有者可以破坏。

## 💰 经济系统
赤城币：虚拟货币，支持命令操作。

命令（所有命令前缀 /chicheng）：

balance – 查看余额

give <玩家> <数量> – 给予赤城币（OP）

take <玩家> <数量> – 扣除赤城币（OP）

set <玩家> <数量> – 设置余额（OP）

transfer <目标玩家> <数量> – 转账给其他玩家

余额 HUD：屏幕右下角显示当前余额（可配置开关）。

配置：可通过 config/chichengjingji-common.toml 修改初始余额（默认 100）。

## 🎨 界面与交互
售货机购买界面：商品列表（显示图标、单价、库存）→ 点击商品进入详情页（放大图标）→ 输入数量购买。

上架界面：直观的输入框和按钮。

收银机转账界面：简洁的数字输入和确认按钮。

所有按钮支持悬停高亮，界面不暂停游戏。

## 📦 安装
确保已安装 NeoForge 1.21.1。

将下载的 chichengjingji-1.0-SNAPSHOT.jar 放入 .minecraft/mods 文件夹。

启动游戏，模组会自动生成配置文件。

多人服务器：只需将 jar 文件放入服务端的 mods 文件夹，所有客户端也需安装该模组（否则无法显示界面）。

## 🕹️ 使用指南
售货机
放置售货机（放置者即所有者）。

手持要出售的物品右键售货机 → 设置单价和数量 → 确认上架。

其他玩家右键（空手）打开购买界面 → 选择商品 → 输入数量 → 购买。

所有者可随时上架新商品或查看收益（收益自动到账/补发）。

收银机
放置收银机（放置者即所有者）。

其他玩家右键收银机 → 输入转账金额 → 确认 → 金额从自己账户扣除并转入所有者账户。

所有者右键收银机仅提示信息，不转账。

经济命令
在聊天栏输入 /chicheng help 查看子命令（实际用法如上所述）。

## ⚙️ 配置
配置文件路径：config/chichengjingji-common.toml

toml
[common]
starting_balance = 100          # 新玩家初始余额
showBalanceHUD = true           # 是否显示余额 HUD
🛠️ 开发者信息
开发环境：NeoForge 1.21.1

语言：Java 21

代码结构：遵循 NeoForge 标准，使用 DeferredRegister 注册内容，网络包使用 CustomPacketPayload + StreamCodec。

构建
bash
gradlew build
生成的 jar 位于 build/libs/。
